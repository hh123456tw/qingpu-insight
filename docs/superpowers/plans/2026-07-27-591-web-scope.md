# 591 Web Scope Reduction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove rental listings from the Web/admin update path while preserving rental code, CLI compatibility, historical jobs, and existing stored data.

**Architecture:** Keep `ListingUpdateRequest` and the underlying listing pipeline capable of explicit rental work for compatibility. Narrow only the Flask Web contract and admin sequencer to the canonical `sale → newhouse` path; old job payloads remain readable because no repository or serialization schema changes.

**Tech Stack:** Python 3.11+, Flask, pytest, browser JavaScript, Node.js contract tests, BeautifulSoup.

## Global Constraints

- Web/admin accepts only `sale` and `newhouse`; `rental` must fail validation before job creation.
- Web requests that omit `types` default to `["sale", "newhouse"]`.
- The admin one-click sequence is exactly `sale → newhouse`.
- Keep rental parser/source code, `ListingUpdateRequest` support, explicit CLI compatibility, historical records, and stored rental data.
- Do not trigger rental delisting, delete rental artifacts, or rewrite the listing pipeline.
- Do not add rental data to model training.
- Follow strict TDD: red test, minimal implementation, green test, commit.

Use it as the only canonical order:

```javascript
function runListingSequence(_a) {
  var types = _a.types, submit = _a.submit,
      waitForTerminal = _a.waitForTerminal,
      onTypeStart = _a.onTypeStart, onTypeDone = _a.onTypeDone;
  var ordered = DEFAULT_LISTING_TYPES.filter(function (type) {
    return types.indexOf(type) !== -1;
  });
  var results = {};
  function step(idx) {
    if (idx >= ordered.length) return Promise.resolve(results);
    var type = ordered[idx];
    onTypeStart(type);
    return Promise.resolve()
      .then(function () { return submit(type); })
      .then(function (job) { return waitForTerminal(job.run_id); })
      .then(function (finalState) {
        results[type] = {
          status: finalState.status,
          output_version: finalState.output_version,
          error_code: finalState.error_code,
        };
        onTypeDone(type, results[type]);
        return step(idx + 1);
      }, function (err) {
        results[type] = {status: "error", error_code: String(err)};
        onTypeDone(type, results[type]);
        return step(idx + 1);
      });
  }
  return step(0);
}
```
