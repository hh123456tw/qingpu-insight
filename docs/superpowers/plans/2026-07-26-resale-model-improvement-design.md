# 中古屋模型與資料科學強化設計

日期：2026-07-26  
狀態：已核准  
適用範圍：期中專題與求職作品集

## 1. 目標

改善青埔中古屋估價模型在時間上漲趨勢與 A18 生活圈的穩定性，同時保留現有的防退步發布門檻。成果直接呈現在既有模型觀測台，形成一條可說明、可重現、可安全發布的資料科學故事。

本次不以更換模型套件或大量調參為主，而是先診斷資料漂移、增加可由現有官方資料穩定產生的衍生特徵，並用一致的時間切分、消融實驗與多時間點回測證明改善來源。

## 2. 現況與問題

- 最新官方資料共有 19,200 筆，日期範圍為 2018-04-13 至 2026-06-12。
- 中古屋可用資料 16,293 筆，足以支撐本專題的區域型模型實驗。
- 預售屋可用資料 2,907 筆，但不在本次優化範圍內。
- 目前候選模型為近期中位數 baseline、Ridge、Random Forest、HistGradientBoosting；沒有使用 XGBoost。
- 最新中古屋候選實驗中，HistGradientBoosting 的整體驗證 MAE 優於 baseline，但 A18 MAPE 從約 17.84% 上升至約 22.42%，因此被既有分區保護門檻擋下。
- 目前正式中古屋模型資料截至 2024-12-12，落後最新官方資料；在房價長期上升的情況下有系統性低估風險。

## 3. 核准決策

- 聚焦中古屋，不同時擴張預售屋。
- 優先改善 A18，且其他生活圈不得明顯退步。
- 使用現有官方資料產生衍生特徵，不串接外部資料。
- 不使用建案名稱或建商，避免高基數記憶、名稱清理與跨時間資料洩漏。
- 不加入 XGBoost；保留為未來工作。
- 不新增模型管理頁面；擴充現有 `/admin#models`。
- 不提供任意調參介面，不允許使用者挑選最好看的測試結果。
- 不自動發布模型；發布仍需通過門檻並由使用者確認。
- 不宣稱預測未來房價，只估計最新資料時間點的合理價格。

## 4. 衍生特徵

所有新特徵都必須由目前估價表單與官方交易資料中已存在的欄位決定，確保訓練與推論一致。

1. `transaction_month_index`
   - 將交易年月轉換為連續月份序號。
   - 用於表達長期價格趨勢，取代僅靠獨立年份與月份捕捉時間的限制。

2. `station_building_type`
   - 組合 `station_code` 與 `building_type`。
   - 捕捉 A17–A19 各自不同產品組成與價差。

3. `building_age_band`
   - 分為 `0_5`、`5_10`、`10_20`、`20_plus`、`missing`。
   - 保留原始連續屋齡，區間特徵作為補充。

4. `area_band`
   - 依中古屋實際坪數分布定義固定且可重現的區間。
   - 保留原始連續坪數，區間特徵作為補充。

5. `floor_band`
   - 依 `floor / total_floors` 分為低樓、中樓、高樓與未知。
   - 保留原始樓層、總樓層與樓層比例。

建案名稱與建商不進入正式特徵契約。若未來研究，必須使用按建案分組的資料切分，且不得以該實驗作為本次發布依據。

## 5. 時間漂移處理

### 5.1 近期加權

- 保留全部歷史資料。
- 以最新資料月份為基準，依成交距今月數計算訓練權重。
- 使用 24 個月半衰期。
- 權重下限為 `0.10`，避免舊資料完全失去影響。
- 權重只用於模型擬合；calibration、test 與回測指標使用未加權的真實誤差。

### 5.2 近期 baseline

- baseline 優先使用最近 12 個月的「生活圈 × 建物類型」單價中位數。
- 群組樣本不足時依序退回最近 12 個月的生活圈中位數、全區中位數。
- baseline 必須與候選模型使用相同的 calibration、test 與回測資料。

### 5.3 模型過期

- 正式模型的資料日期若落後最新官方資料超過 180 天，狀態標示為 `stale`。
- 模型觀測台明確顯示資料日期、落後天數與過期警告。
- 過期時首頁估價改用最近 12 個月 baseline，回應標記為降級估價並說明原因。
- 新正式模型通過發布後，估價自動恢復使用正式模型。

## 6. 實驗設計

每次中古屋訓練固定執行：

1. 近期 baseline。
2. 原始 15 特徵的既有候選模型。
3. 原始特徵加 5 個衍生特徵的增強候選模型。
4. 逐組移除衍生特徵的消融實驗。

所有實驗使用相同時間切分、相同資料品質規則與相同指標。不得因模型不同而變更 test 範圍。

訓練前產生 A18 診斷：

- 各年月筆數與單價中位數。
- 各建物類型的筆數與誤差。
- 特徵缺值率與極端值比例。
- A17–A19 資料量差異。
- train、calibration、test 的價格與產品組成漂移。

## 7. 多時間點回測

- 使用最近三個可成立的年度截止點回測。
- 每個截止點只能使用當時已存在的資料訓練。
- 每期輸出整體 MAE、MAPE、RMSE、R²，以及 A17–A19 MAPE。
- 至少兩期必須優於同期 baseline。
- 至少兩期的 A17–A19 必須全數維持在同期 baseline 的 10% 防退步限制內。

## 8. 發布資格

中古屋候選模型只有同時符合以下條件才標示為可發布：

1. 最新 test 整體 MAE 至少比 baseline 改善 2%。
2. A17、A18、A19 的 MAPE 均不得比 baseline 惡化超過 10%。
3. A18 MAPE 必須低於 baseline。
4. 最近三期回測至少兩期優於 baseline。
5. 最近三期回測至少兩期的生活圈均符合 10% 防退步限制。
6. 候選模型資料日期距離最新官方資料不超過 180 天。

未通過時保留現有正式模型；若現有正式模型已過期，估價服務使用近期 baseline 降級，不得默默使用過期模型。

## 9. 產物與相容性

候選 manifest 新增：

- 特徵契約版本與完整特徵清單。
- 近期加權設定。
- 資料診斷摘要。
- 原始與增強模型比較。
- 衍生特徵消融結果。
- 三期時間回測結果。
- 每一項發布條件的布林結果與原因代碼。

舊 manifest 必須保持可讀。缺少新欄位時，模型觀測台顯示「舊版模型未包含此分析」，不得因欄位缺失造成頁面或 API 錯誤。

## 10. 模型觀測台

沿用 `/admin#models`，點選訓練紀錄後顯示：

- 資料筆數、日期範圍、各生活圈筆數與缺值摘要。
- baseline、Ridge、Random Forest、HistGradientBoosting 的整體比較。
- A17–A19 分區 MAPE，A18 改善或退步以視覺狀態呈現。
- 原始特徵、完整增強特徵與消融組合比較。
- 三期時間回測。
- 每一項發布門檻的通過／失敗結果。
- 最終推薦發布或保留正式模型的明確原因。
- 正式模型的資料日期、落後天數與 stale 狀態。

## 11. 非目標

- XGBoost、CatBoost 或大型超參數搜尋。
- 建案名稱、建商或高基數社區記憶。
- 學區、人口、商圈等外部資料。
- 通用實驗追蹤平台。
- 任意命令或任意路徑輸入。
- 自動模型發布。
- 未來房價預測。

## 12. 驗證

- 功能實作階段嚴格採 TDD：每一項新行為先寫失敗測試、確認紅燈、完成最小實作、確認綠燈，再重構。
- 全部功能完成後的 review 與驗收修復不要求 TDD；可依 review finding 直接修正，但每次修正後仍須執行相關測試，最終執行完整驗證。
- 衍生特徵在訓練與推論產生完全一致。
- 近期權重只影響擬合，不影響報告指標計算。
- 時間回測不存在未來資料洩漏。
- 舊 manifest 與舊正式模型仍可載入。
- 正式模型過期時，估價確實降級並揭露原因。
- 模型觀測台能處理完整新產物與缺欄位舊產物。
- 完整 Python 測試、Node contracts 與 Ruff 檢查通過。
