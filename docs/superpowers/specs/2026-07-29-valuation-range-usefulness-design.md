# 估值範圍可用性設計

## 問題

目前畫面將校準誤差第 90 百分位產生的區間稱為「合理估值區間」。該區間的
用途是描述模型不確定性，不是市場可能成交價格。每坪固定誤差乘上大坪數後，
總價上下限可能相差超過一千萬元，雖然統計定義正確，但不適合作為主要出價
參考。

## 核准方向

- 主要顯示模型估值點。
- 使用至少 3 筆、相似度 `>= 0.60` 的成交案例，以房屋本體單價第 25～75
  百分位乘上物件坪數，再加模型車位估值，形成「相似成交價格帶」。
- 591 開價相對位置改與相似成交價格帶比較。
- 原本的 90% 區間改稱「模型保守範圍（90%）」並預設收合。
- 保守範圍寬度超過模型估值點 40% 時，標示「參考性低，不建議單靠模型
  範圍判斷出價」。
- 高相似案例少於 3 筆時不產生成交價格帶，也不以低相似案例補足。

## 資料來源

對話證據優先使用估值服務已選出的模型可比案例。案例必須保留
`similarity_score`、房屋本體單價、交易日期、距離與總價。只有模型沒有返回
案例時，才沿用目前以面積、距離與日期排序的市場案例；後者不具相似度分數，
因此不能用來計算成交價格帶。

## 相容與降級

- 不修改資料庫 schema。
- 舊證據沒有相似度或房屋本體單價時，只顯示模型估值點、信心與 591 開價。
- 舊的 90% 上下限仍保留於 API 和證據中。
- 不修改或回填歷史訊息內容。
- 不手動縮窄 90% 區間，避免製造假精準。

## 驗證

- 第 25／75 百分位使用線性插值並可重現。
- 僅納入相似度 `>= 0.60` 且單價有效的案例。
- 車位估值只加一次。
- 少於 3 筆案例時成交價格帶為空。
- 寬度比例以 `(high - low) / point` 計算。
- 桌面與窄螢幕均能閱讀，兩個 `<details>` 預設保持收合。
