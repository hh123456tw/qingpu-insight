# 車位估值一致性設計

日期：2026-07-28
狀態：已核准

## 背景

目前 AI 條件估價在其他條件完全相同時，可能出現有車位的估計總價低於無車位。以 A18、中古屋、30 坪、屋齡 5 年的固定條件實測：

- 無車位：約 1,686 萬
- 坡道平面、車位面積 0 坪：約 1,333 萬
- 坡道平面、車位面積 8 坪：約 1,408 萬
- 坡道機械、車位面積 5 坪：約 1,513 萬

這不是可接受的產品行為，也不符合使用者對「房屋坪數不含車位」的輸入認知。

## 根因

1. 中古屋訓練資料的車位類型高度不平衡：坡道平面約 14,955 筆，無車位約 799 筆。
2. 現行 HistGradientBoosting 模型把 `parking_type` 與 `parking_area_ping` 當成房屋單價特徵，會學到資料中的非因果關聯。
3. 訓練目標在有可靠車位價與面積時，會扣除車位價與車位坪數，形成房屋本體單價；但推論時仍以預測單價直接乘上房屋坪數，沒有一致地將車位價值加回。
4. 前端允許「有車位但車位面積為 0」的矛盾輸入。

## 使用者輸入語意

- `building_area_ping`：房屋本體坪數，不含車位。
- `parking_type`：車位類型；空字串代表無車位。
- `parking_area_ping`：車位面積，只用於資訊呈現與合理性驗證，不進入房屋單價模型。

首頁欄位名稱必須明確顯示「房屋坪數（不含車位）」。

## 估價架構

### 房屋本體模型

模型只估算房屋本體每坪價格。新版訓練特徵排除：

- `parking_type`
- `parking_area_ping`

其他既有時間、地點、建物、格局與樓層特徵維持不變。

### 車位估值政策

每次訓練從該市場的訓練資料建立車位價格政策：

1. 只使用 `parking_price_twd > 0` 的有效資料。
2. 依 `parking_type` 計算車位價格中位數及樣本數。
3. 未達最低樣本數的類型不得單獨發布價格，改用市場層級有效車位價格中位數。
4. 無車位的車位估值固定為 0。
5. 車位類型無法對應且沒有市場 fallback 時，拒絕估價並回傳明確欄位錯誤，不得靜默當成 0。

車位價格統計必須隨模型 artifact 一同保存，確保訓練、發布、回滾與推論使用同一版本政策。

### 總價公式

```text
房屋估值 = 房屋坪數 × 房屋本體預測單價
車位估值 = 該市場與車位類型的中位車位價格
估計總價 = 房屋估值 + 車位估值
```

估價區間的上下限都加上相同車位估值。信心度仍以房屋模型與相似案例評估，但若車位價格使用市場 fallback，需增加一條限制說明。

## API 契約

保留現有欄位，新增：

- `estimated_building_price_twd`
- `estimated_parking_price_twd`
- `parking_price_policy`
  - `parking_type`
  - `sample_size`
  - `source`：`type_median`、`market_median` 或 `none`

`estimated_total_price_twd` 與 `interval_total_price_twd` 必須包含車位估值。

為相容舊 artifact：

- 若 bundle 沒有車位價格政策，系統仍可載入。
- 舊模型推論必須標示 legacy 限制，不得假裝已套用新版車位估值。
- 新版正式模型發布後，首頁才顯示拆分後的車位估值。

## 前端

1. 「坪數」改為「房屋坪數（不含車位）」。
2. 選擇無車位時：
   - 車位面積自動設為 0。
   - 車位面積欄位停用。
3. 選擇任一車位類型時：
   - 車位面積欄位啟用。
   - 必須大於 0，否則在欄位旁顯示錯誤並阻止送出。
4. 估價結果拆成：
   - 房屋本體估值
   - 車位估值
   - 估計總價
5. 車位估值顯示使用的統計來源與樣本數，但以一句簡短說明呈現。

## 管理中心與模型報告

模型報告增加：

- 房屋模型是否排除車位特徵。
- 各車位類型中位價與有效樣本數。
- fallback 車位價格。
- 車位政策版本。
- 「同條件有車位總價不得低於無車位」一致性檢查結果。

發布 smoke test 加入至少一組無車位／坡道平面／坡道機械反事實比較。若有效車位的估計總價不高於無車位，候選模型不得發布。

## 驗證

### 自動驗證

- 相同房屋條件下：
  - 無車位估值等於房屋本體估值。
  - 有效車位估值等於房屋本體估值加車位中位價。
  - 坡道平面與坡道機械總價都高於無車位。
- 車位類型不再改變房屋本體預測單價。
- 有車位且面積為 0 時，API 與前端都拒絕。
- 無車位時忽略外部殘留的車位面積並正規化為 0。
- artifact 發布、載入及回滾保留同一份車位價格政策。
- 舊 artifact 仍可載入並回傳 legacy 限制。

### 真實驗證

以目前正式中古屋模型的固定條件比較無車位、坡道平面與坡道機械，確認：

- 畫面顯示房屋、車位、總價拆分。
- 有車位總價高於無車位。
- 所有金額使用「萬」顯示。
- 模型報告可看到車位政策與樣本數。

## 不在本次範圍

- 不建立獨立車位 ML 模型。
- 不加入 AutoML。
- 不加入模型單調約束。
- 不改動 591 刊登爬蟲。
- 不將車位面積當成房屋本體價格的加價特徵。
