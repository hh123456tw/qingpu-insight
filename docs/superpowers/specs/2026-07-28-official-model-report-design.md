# 正式模型詳細數據與管理中心配色設計

日期：2026-07-28  
狀態：使用者已核准

## 目標

讓管理中心的「目前正式模型」直接顯示正式 artifact 已保存的評估資料，並讓管理中心配色與產品首頁一致。此功能不重新訓練模型、不修改資料庫，也不新增報告檔案。

## 正式模型報告

`ModelObservatory.status()` 從目前正式 `ValuationBundle` 投影公開且可序列化的報告資料：

- 資料起訖日期與測試筆數
- 整體 MAE、MAPE、RMSE、R²
- A17、A18、A19 分站 MAE、MAPE 與筆數
- 前五項重要特徵
- 發布時間、來源訓練 ID、正式版本 ID

既有 `/api/admin/models/status` 直接包含上述資料，不新增 API。不得回傳 estimator、訓練資料、內部絕對路徑或完整 artifact 內容。

每張正式模型卡提供原生 `<details>` 展開區塊，預設收合。指標附簡短中文說明；缺少欄位時顯示「—」，不能因此讓整張卡失敗。發布資格只標示「目前正式使用中」，不推算已遺失的歷史發布閘門。

## 視覺

管理中心沿用首頁的米白背景、白色卡片、墨綠主色、深色文字與淡灰邊框。只調整顏色變數與必要元件顏色，不改導覽、表單或操作位置。

## 驗證

- Python 測試確認正式模型狀態只投影安全報告欄位，並兼容缺少新欄位的舊 artifact。
- JavaScript 契約確認報告 view model 能處理完整與缺漏資料。
- 真實瀏覽器確認兩張正式模型卡可展開、管理中心配色一致，既有操作仍可使用。
