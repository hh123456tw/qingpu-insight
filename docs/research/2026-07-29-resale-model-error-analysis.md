# 中古屋估價誤差研究：從 RMSE 異常到可治理模型

日期：2026-07-29

範圍：青埔 A17、A18、A19 中古屋估價

目的：降低少數極端案件對模型的影響，並留下可供期中報告與求職面試說明的研究紀錄。

## 1. 問題怎麼被發現

原正式模型頁面顯示 MAE 約 5.9 萬／坪、MAPE 15.22%、RMSE 約 12.2 萬／坪、R² 0.456。RMSE 明顯高於 MAE，表示誤差集中在少數案件。另外，管理頁當時把候選選擇用的校準集指標顯示成正式模型報告。

重新讀取候選報告後，真正未參與選模的 final test 為 696 筆：

| 指標 | Final test |
| --- | ---: |
| MAE | 5.38 萬／坪 |
| MAPE | 16.51% |
| RMSE | 7.52 萬／坪 |
| R² | 0.635 |

第一個工程問題不是立刻換模型，而是先修正「評估資料來源」與「報告語意」。

## 2. 最大誤差從哪裡來

以相同時間切割與近期權重重建原 HGB 後：

- 最大 1% 誤差案件貢獻約 14.0% 的平方誤差。
- 最大 5% 貢獻約 42.7%，最大 10% 貢獻約 61.1%。
- 63 筆特殊關係交易的 MAE 約 11.0 萬／坪、MAPE 約 47.9%，貢獻約 29% 的平方誤差。
- 最大誤差前 20 筆中，11 筆有親友、員工、共有人或其他特殊關係備註，10 筆的交易標的是只有「建物」。

這些資料不是一般公開市場房地成交。若直接當成正常住宅交易標籤，模型會學到錯誤價格關係。

## 3. 實驗結果

所有結果皆使用時間切割，避免用未來資料預測過去。

| 實驗 | MAE | MAPE | RMSE | R² |
| --- | ---: | ---: | ---: | ---: |
| 原流程 | 5.38 萬／坪 | 16.51% | 7.52 萬／坪 | 0.635 |
| 排除特殊關係與純建物交易 | 4.83 萬／坪 | 14.06% | 6.33 萬／坪 | 0.727 |
| 再加入 TWD97 空間座標 | 4.23 萬／坪 | 11.00% | 5.76 萬／坪 | 0.774 |

空間位置是這次最有效的新增特徵。同一個捷運生活圈內，不同路段、重劃區位置與距離仍有價格差異；只用 A17／A18／A19 類別與捷運距離不足以表達這些差異。

### 路段類別為何沒有直接加入正式特徵

當期測試中，原始 `road_key` 類別的 R² 約 0.778，略高於座標 0.774；但在 2025 年回測中，路段類別 R² 只有約 0.098，而座標仍有約 0.380。路名容易遇到新道路、樣本稀疏與類別漂移，因此選擇較穩定、可連續表達位置的 TWD97 座標。

### 為何沒有整批刪除「預售屋、或土地及建物分件登記案件」

這段備註在清理後中古屋資料中仍有 10,672 筆。它在部分期間確實形成分布漂移，但整批刪除會大幅縮小樣本，並使當期模型表現惡化。因此本次只把它列為資料品質診斷，不直接當作排除條件。

## 4. 採用的修正

1. 只允許 `房地(土地+建物)` 與 `房地(土地+建物)+車位` 進入市場模型。
2. 排除親友、員工、共有人、特殊關係與二等親交易。
3. 新模型 artifact 明確保存 `final_test` 指標；舊模型標示來源未知。
4. 特徵契約升級為 v3，加入 `twd97_x`、`twd97_y` 與 `location_known`。
5. 591 詳細頁經緯度會轉成 EPSG:3826；手動估價缺少精確位置時仍可使用，但會顯示限制。
6. 加入 HGB（對數價格）候選；只有通過校準、final test 與年度回測才可發布。
7. 模型產物保存前 20 筆最大誤差與資料品質計數；管理頁預設收合，且不公開完整門牌。

## 6. 模型治理原則

- 校準集只負責選候選，final test 不參與選模。
- 新候選不會自動取代正式模型。
- 發布仍須通過整體 MAE、各站 MAPE、A18、三期年度回測、資料新鮮度與車位一致性。
- 若新特徵只改善當期、卻讓歷史回測明顯退步，就不採用。
- R² 不是唯一目標；還要看 MAE、MAPE、RMSE、分站誤差與服務端可解釋性。

## 7. 期中報告可用摘要

本研究先從「RMSE 遠高於 MAE」判斷誤差集中於少數案件，再以 residual analysis 發現特殊關係交易與純建物交易大量出現在最大誤差清單。清理確認的非市場交易後，加入 TWD97 空間座標，使離線實驗 R² 由 0.635 提升至 0.774、MAE 由 5.38 萬／坪降至 4.23 萬／坪。系統同時修正校準集與 final test 報告混淆，並把最大誤差、資料品質與跨年度回測整合進模型觀測台。

## 8. 求職面試 STAR 說法

- **Situation**：模型 R² 只有中等、RMSE 遠高於 MAE，而且管理頁的正式成績來源不正確。
- **Task**：找出誤差根因，在不過度複雜化 side project 的前提下提升可靠性。
- **Action**：做時間外 residual analysis、辨識非市場交易、比較路段與空間座標、加入 log-target 候選，並補上 final-test 與年度回測治理。
- **Result**：離線實驗將 MAE 從 5.38 降至 4.23 萬／坪、R² 從 0.635 提升至 0.774；同時產出可追溯的資料排除原因與模型報告。

## 9. 後續研究方向

1. 觀察新 v3 模型在 A18 與 2025 回測的穩定性。
2. 補足建案名稱或建商時，先做低基數、可回測的品牌統計特徵，避免直接 one-hot 全部名稱。
3. 針對高價尾端、特殊樓層與非典型產品建立分群診斷，不急著再加更複雜模型。
4. 累積新季度資料後重新檢查區間覆蓋率，再決定是否做分群 conformal interval。
